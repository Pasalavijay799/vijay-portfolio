# Vijay Kumar Pasala — Portfolio

Dark PCB-themed portfolio with live, procedurally-modelled 3D circuit boards (React Three Fiber).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

1. Put your photo at `public/profile.jpg`
2. ECE portal screenshots live in `public/projects/ece-*.jpg` (listed in `profile.ts` → `gallery`)
3. Edit any text in `src/data/profile.ts`

See **PLAN.md** for the roadmap and **CLAUDE.md** for Claude Code instructions.
